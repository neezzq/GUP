---
name: windows-ui-automation
description: Inspect and safely automate installed official launchers on Windows.
---
Use Inspect.exe and pywinauto UIA in an isolated maintenance session. Verify signed publisher,
PID, image path and control context. Record build and locale for each UI contract. Refuse ambiguous
login and update controls and request administrator action for challenges. Verify a real pending
update through download, file installation and settled state.
References: https://github.com/pywinauto/pywinauto and https://learn.microsoft.com/windows/win32/winauto/
